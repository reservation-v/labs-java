# Лабораторная работа №1 (вариант 9)

Вариант: `HashSet<String>` - уникальные комбинации `species - gender`.

## Что делает программа

1. Читает персонажей Рика и Морти из CSV.
2. Собирает уникальные комбинации вида `species - gender` в `HashSet<String>`.
3. Пишет результат в текстовый файл (комбинации отсортированы для стабильного вывода).
4. Демонстрирует CRUD (создание, обновление, удаление) персонажей в CSV.

## Сборка и запуск

```bash
mvn clean package
java -jar target/lab-1-1.0.0-SNAPSHOT-fat.jar
```

Производить запуск в директории lab-1, потому что артефакты сборки сохраняются внутри target.

## Результат

Файл `target/unique-species-gender.txt` в рабочей директории запуска и уникальные комбинации видов и полов.
